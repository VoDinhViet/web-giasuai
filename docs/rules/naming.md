# Naming Rules

- Dùng kebab-case cho file: `create-user-dialog.tsx`.
- Dùng PascalCase cho component: `CreateUserDialog`.
- Ưu tiên named export cho component và helper.
- Đặt tên theo nghiệp vụ rõ nghĩa: `userId`, `courseCode`, `classCode`, `roleId`.
- Tránh tên mơ hồ: `data`, `item`, `record`, `result`, `tmp`, `obj`, `val`, `arr`.
- Dùng `reqDto` cho một request DTO sau khi parse/validate input.
- File utility dùng hậu tố `.util.ts` khi là utility thuần.
