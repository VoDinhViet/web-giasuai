# Git Rules

- Không commit nếu user chưa yêu cầu rõ.
- Không revert thay đổi của user.
- Không dùng destructive commands như `git reset --hard` hoặc `git checkout --` nếu chưa được yêu cầu rõ.
- Worktree có thể dirty; chỉ sửa file liên quan request.
- Nếu gặp thay đổi ngoài phạm vi, bỏ qua.
- Nếu thay đổi ngoài phạm vi ảnh hưởng trực tiếp task, đọc kỹ và làm việc cùng thay đổi đó.
